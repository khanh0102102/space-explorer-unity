# Kenney asset location

Copy the contents of your downloaded kenney_space-shooter-remastered folder into this folder, keeping these directories:
- Backgrounds/
- PNG/
- Bonus/
- license.txt

Expected example: Assets/Art/KenneySpaceShooter/PNG/playerShip1_blue.png.

Then run Tools → Space Explorer → Tạo toàn bộ dự án in Unity. The editor tool will import PNG files as Sprites and rebuild the scenes/prefabs using these assets.
